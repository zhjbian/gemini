我实现的"Order Flow 核心指标判定方向"规则详解

核心思路：解耦出一个纯 OrderFlow 方向（of_direction）

它只依赖 4 个核心微观指标的量价/盘口信号，与价格位置（第一道门）、非接飞刀无关——这正是要能在图上看到"OrderFlow 看多但当前不宜开仓"的原因。

一、4 个核心指标（对应第二道门的分支）

分支 指标 权重 触发条件（看多）
b1 量价背离（四象限） 3 象限I 被动吸收：delta_ratio <= -15% 且 price_change_atr >= -0.6；或 象限II 主动承接：delta_ratio >= +15% 且 price_change_atr <= -0.5
b2 盘口大翻转 1 book_flip_bull == True（前半段<0.85 到 后半段>1.40）
b3 密集冰山/吸收 1 absorption_bull >= 1 或 iceberg_bull >= 1 且 > iceberg_bear，且 last_5m_delta >= -300
b4 2h 机构大单 1 inst_bull_accumulation == True（大单净量>=3000 或评分>=1500 且 Pos<=45%）

看空对称（象限III被动拦截/象限IV主动压制、book_flip_bear、iceberg_bear、inst_bear_distribution，且 last_5m_delta <= +300）。

二、核心规则：加权计分（of_direction）

branch_score = b1*3 + b2*1 + b3*1 + b4*1   # 加权
of_bull_raw = (branch_score >= 2)           # 门槛=2

# 一票否决(只含撤单陷阱 + 大单逆势, 不含物理门槛/非接飞刀)
_of_blocked_bull = block_bull_by_spoof or (big_trade_net_2h <= -3000)
of_bull_ok = of_bull_raw and not _of_blocked_bull

加权逻辑：
- b1 量价背离是核心（权重3）：单独即通过（3>=2）
- 辅助指标（b2/b3/b4 各权重1）：需 >=2 个聚合（2>=2）才通过
- 单一辅助（1分）不通过

最终方向：

of_bull_ok 且 not of_bear_ok -> Bullish
of_bear_ok 且 not of_bull_ok -> Bearish
否则 -> Neutral

三、与"是否开仓"（trade_decision）的关键区别

of_direction trade_decision
依据 纯 4 核心指标加权 + 一票否决 第一道门物理门槛 + of_direction + 一票否决
受价格位置影响 不受 受（超卖/超买区路径 A/B/C）
受非接飞刀影响 不受 受
用途 展示 OrderFlow 真实方向 决定能不能开仓

四、四象限背离的具体对称结构

看多（价格偏跌方向）：
- 象限I 被动吸收（净卖但跌不动）：dr <= -15% 且 atr >= -0.6
- 象限II 主动承接（跌中净买）：dr >= +15% 且 atr <= -0.5
- 两者互斥（dr 只有一个符号）

看空（价格偏涨方向）：
- 象限III 被动拦截（净买但涨不动）：dr >= +15% 且 atr <= +0.6，且 atr >= -0.5（防止与看多象限II重叠）
- 象限IV 主动压制（涨中净卖）：dr <= -15% 且 atr >= +0.5

五、强度打分（of_strength）

对 of_direction 为 Bullish/Bearish 时，用现行加分项累加（1~10）：
- Bullish：30m 推进、10m/5m 动能、DOM失衡、真空、吸收/冰山、2h大单、趋势日共振、5m/10m早警...
- Bearish：对称

六、为什么这样设计

  1. 4 核心指标 vs 物理位置解耦：OrderFlow 方向（量价/盘口）与"是不是开仓好位置"（价格在不在超卖/超买区）是两个独立判断。图上可以显示"OrderFlow 看多但价格不在低位 -> 观望"。

  2. 量价背离权重最高（3）：因为它是最核心、最可靠的方向信号（四象限覆盖被动吸收+主动承接），符合你"量价背离最重要、单独通过"的要求。

  3. 一票否决较宽松（只含撤单陷阱+大单逆势）：of_direction 是方向判定，不掺入物理门槛的风控因素，才能真实反映 OrderFlow 是否看多/看空。

  4. 屏蔽了非接飞刀：这是特意为之——of_direction 看的是"盘面力量方向"，而接飞刀是开仓时机的考量，两者不应混淆。图上就能看到"OrderFlow 看多（接飞刀时）但观望"。

一句话总结

of_direction = 4 个核心指标加权（量价背离权重3 为核心，辅助>=2 聚合）来 判多空 来 扣撤单/大单一票否决，产出纯 OrderFlow 方向；trade_decision 再叠加第一道门物理位置决定能否开仓。这样用户在图上能看到 OrderFlow 的真实方向，同时知道现在是不是开仓时机。

附：Key 代码段（order_flow_rules_optimizer.py）

量价背离四象限（与 b1 判据一致）：

_of_passive_bull = (delta_ratio_15m <= -THRESHOLDS["absorb_delta_ratio"] and price_change_atr_15m >= -THRESHOLDS["absorb_price_atr"]) or (delta_ratio_30m <= -THRESHOLDS["absorb_delta_ratio"] and price_change_atr_30m >= -THRESHOLDS["absorb_price_atr"])
_of_active_bull = (delta_ratio_15m >= THRESHOLDS["active_absorb_delta_ratio"] and price_change_atr_15m <= -THRESHOLDS["active_absorb_price_atr"]) or (delta_ratio_30m >= THRESHOLDS["active_absorb_delta_ratio"] and price_change_atr_30m <= -THRESHOLDS["active_absorb_price_atr"])
_of_div_bull = _of_passive_bull or _of_active_bull
_of_b1 = _of_div_bull; _of_b2 = is_book_flip_bull
_of_b3 = (absorption_bull >= 1 or (iceberg_bull >= 1 and iceberg_bull > iceberg_bear)) and last_5m_delta >= -THRESHOLDS["absorption_last5m_subsided"]
_of_b4 = inst_bull_accumulation
_of_branch_score = int(_of_b1) * wb1 + int(_of_b2) * wb2 + int(_of_b3) * wb3 + int(_of_b4) * wb4
_of_bull_raw = (_of_branch_score >= branch_min_score)

看空背离：

_of_passive_bear = (delta_ratio_15m >= THRESHOLDS["absorb_delta_ratio"] and price_change_atr_15m >= -THRESHOLDS["absorb_price_atr"] and price_change_atr_15m <= THRESHOLDS["absorb_price_atr"]) or (delta_ratio_30m >= THRESHOLDS["absorb_delta_ratio"] and price_change_atr_30m >= -THRESHOLDS["absorb_price_atr"] and price_change_atr_30m <= THRESHOLDS["absorb_price_atr"])
_of_active_bear = (delta_ratio_15m <= -THRESHOLDS["active_absorb_delta_ratio"] and price_change_atr_15m >= THRESHOLDS["active_absorb_price_atr"]) or (delta_ratio_30m <= -THRESHOLDS["active_absorb_delta_ratio"] and price_change_atr_30m >= THRESHOLDS["active_absorb_price_atr"])
_of_div_bear = _of_passive_bear or _of_active_bear
_of_b1b = _of_div_bear; _of_b2b = is_book_flip_bear
_of_b3b = (absorption_bear >= 1 or (iceberg_bear >= 1 and iceberg_bear > iceberg_bull)) and last_5m_delta <= THRESHOLDS["absorption_last5m_subsided"]
_of_b4b = inst_bear_distribution
_of_branch_score_b = int(_of_b1b) * wb1 + int(_of_b2b) * wb2 + int(_of_b3b) * wb3 + int(_of_b4b) * wb4
_of_bear_raw = (_of_branch_score_b >= branch_min_score)

一票否决与方向定夺：

_of_blocked_bull = block_bull_by_spoof or (big_trade_net_2h <= -THRESHOLDS["big_trade_block_net"])
_of_blocked_bear = block_bear_by_spoof or (big_trade_net_2h >= THRESHOLDS["big_trade_block_net"])
of_bull_ok = _of_bull_raw and not _of_blocked_bull
of_bear_ok = _of_bear_raw and not _of_blocked_bear
if of_bull_ok and not of_bear_ok:
    of_direction = "Bullish"
elif of_bear_ok and not of_bull_ok:
    of_direction = "Bearish"
else:
    of_direction = "Neutral"
