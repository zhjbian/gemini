二、背离 (Divergence) 类型学与检测方法

2.1 背离的本质：两个变量方向打架

订单流背离的核心是 Delta（主动买卖净额）与价格两个变量出现方向不一致。当前引擎的 A+B 归一化把这两者标准化为可比较的量纲：

  • X 轴 (价)：price_change_atr = 价格变化 ÷ ATR（归一化"价格移动了多少倍波动"）
  • Y 轴 (量)：delta_ratio = 净 Delta ÷ 成交量（归一化"每单位成交中净主动买卖占比"）

关键：delta_ratio 的符号用于判断主动方向（+ = 净买，- = 净卖），价格方向用 price_change_atr 的符号判断。

2.2 4 象限背离矩阵（核心框架）

把价格方向与 Delta 方向组合成 4 种情景，引擎的 A+B 判据只覆盖了其中 1 种：

象限 价格方向 Delta 方向 delta_ratio price_change_atr 背离性质 引擎策略
I 跌 净卖 <= -0.20 但不深跌(>= -0.5) 卖方被吸收（底背离，抛压撞墙） 已实现 (底背离)
II 跌 净买 > 0 负 净买承接（买盘接下跌） 未检测（07:10 场景）
III 涨 净买 >= +0.20 但不深涨(<= +0.5) 买方被拦截（顶背离，涨势遇阻） 已实现 (顶背离)
IV 涨 净卖 < 0 正 净卖压制（卖盘压上涨） 未检测

本质上：
- I/III 象限 = 被动吸收型背离：主动方（卖/买）猛攻，但主力被动单把它吞掉，价格不动。这是"主力用隐藏单（冰山/吸收）对抗散户主动单"，方向跟随主动方的反向（卖被吸收→看多）。
- II/IV 象限 = 主动承接/压制型背离：价格走某方向，但主动单却流向反向。这是"主力主动单先行、价格随后跟上"，方向跟随主动单方向（净买承接下跌→看多）。

2.3 为什么引擎只实现了 I/III（被动吸收型）

引擎的 A+B 判据精确对应 I/III：

delta_ratio <= -20% (净卖占比高)  AND  price_change_atr >= -0.5 (价格没跌透)
    = 卖方猛攻但价格跌不动 -> 买盘被动吸收 -> 看多 (底背离)

这背后的哲学是 MotiveWave 做市商对冲视野：逆势被动单是"墙"，抗住了散户顺势单就是反转信号。它相信"卖压被吸收"比"买盘主动进场"更可靠——因为被动大单是主力真实意图，主动单可能是散户/算法噪音。

2.4 象限 II（净买承接）为什么 07:10 没被识别

07:10 的数据：
- 价格：07:05–07:10 = -5.50（跌）
- Delta：+668（净买）
- delta_ratio = +3.43%（正，净买占比）
- price_change_atr = 负

这是象限 II（净买承接）：价格跌，但主动单是净买入。引擎判据要求 delta_ratio <= -20%（净卖），所以方向条件不匹配 → 不触发。

2.5 如何检测和使用象限 II/IV

2.5.1 检测（对称化判据）

净买承接型底背离（象限 II）：

delta_ratio >= +20% (净买占比高)  且  price_change_atr <= -0.5 (价格明显下跌)
    = 价格跌但主动单净买 -> 主力主动吸筹 -> 看多

净卖压制型顶背离（象限 IV）：

delta_ratio <= -20% (净卖占比高)  且  price_change_atr >= +0.5 (价格明显上涨)
    = 价格涨但主动单净卖 -> 主力主动派发 -> 看空

2.5.2 与象限 I/III 的本质区别

I (被动吸收) II (主动承接)
Delta 符号 负（净卖） 正（净买）
价格 跌但跌不动 明显下跌
看多机制 卖压被墙吃掉 主力主动买盘在跌中进场
置信度 高（被动大单=主力真意图） 中（需确认买盘持续）
风险 墙可能被击穿 可能是"接飞刀"

2.5.3 使用建议（引擎取舍）

  1. 象限 II 作为 Setup 1A 的补充分支，但降低优先级：它本质是"跌中接盘"，有接飞刀风险。建议：
    - 单独标记为 Setup 1A-divergence-active-buy（主动承接型），与"被动吸收型"区别
    - 必须叠加非接飞刀过滤（not_falling_knife）——07:10 恰好 _lows[-1] < _lows[-2] 仍创新低，所以即使检测到也被拦
    - 配合 book_flip 或 DOM 动量转正（07:10 有 imb_momentum=+0.047）做确认，避免单纯 delta 正就进
  2. 象限 II 更适合作为"加分项"而非"准入分支"：因为它是"强动能承接"，用在第二部打分里加强度分更合理（比如"价格跌但 Delta 净买 > 3000 手"给额外分），而不是单独准入。
  3. 象限 I 保持主准入：被动吸收型背离是主力隐藏单对抗散户，置信度最高、最可靠。

2.6 落地到检测代码的具体方案

在 Setup 1A 的第二道门，新增一个"主动承接"分支（与现有分支 b1 并列但独立标记）：

# 现有 b1: 被动吸收型背离 (delta_ratio 为负)

# 新增: 主动承接型背离 (delta_ratio 为正, 象限 II)

但强烈建议把它当作需额外确认的加分/辅助信号：

# 建议用法: 主动承接背离 仅作为加分确认, 不单独作为准入分支
if active_absorb_bull and not_falling_knife_bull:
    bonus_items.append("主动承接背离(跌中净买)")

2.7 07:10 的完整诊断（新框架重看）

07:10 处于象限 II（净买承接）：

3.4 为什么拉长窗口会中和？

用户直觉前半对：15m/30m 因为包含前段的深跌（-17.5点），把"价跌"分量放大（价/ATR 从 -1.0 放大到 -3.78），让背离的价格确认（需要"价/ATR>= -0.5"即跌不动）更不满足。

但关键：背离判据的核心约束不是价格，而是 Delta占比必须 >= +-20%。而无论是 5m/10m 还是 15m/30m，Delta占比都只有 3% 左右，从未逼近 20%。所以窗口缩短不会让背离达标——因为它缺的不是"价格确认"，而是"delta 强度"。

结论：07:00-07:15 实测，5m/10m 量价背离/衰竭均未达标。这是正确的保守结果，不是窗口中和的问题。真正的看多信号（如果有）需要 delta_ratio 达到 +-20% 的强主动承接/压制才会触发，而本时段只是温和净买。

四、Δ占比阈值统计依据（20% / 12%）

4.1 两个阈值不是同一来源

阈值 来源 定性
20%（主准入） 系统既有值（规则手册、原引擎代码、config 里原本就是 0.20） 继承自原引擎，非本次发明
12%（方案C预警） 新设的低门槛，取"20% 的 0.6 倍" 经验取值，无回测/统计支撑

诚实声明：12% 是由工程直觉选择的（隔出一个安全裕度，低于主门槛），没有跑回测验证。用真实数据补上了依据。

4.2 21 交易日 1285 根 5m bar 实测统计

统计 2026 年 ES 全部可用的 21 个 TICKS 文件、1285 根 5m bar 的 |Δ占比| 分布：

|Δ占比| 分位数：
- P50 = 4.23%（中位数）
- P70 = 6.47%
- P80 = 8.00%
- P90 = 10.47%
- P95 = 13.13%
- P98 = 16.74%
- P99 = 19.14%
- 均值 = 5.21%

超过 ±20% 的比例 = 0.93%（极罕见，安全边际极高）
超过 ±12% 的比例 = 6.69%（中等）
超过 ±10% 的比例 = 11.44%（较常见）

4.3 这个分布说明了什么

4.3.1 20% 是极罕见极端事件门槛

  • 只有 0.93% 的 5m bar 能达到 ±20%，即约每 107 根 bar 出现 1 次
  • 这正是引擎"宁缺毋滥"哲学的体现：±20% 意味着几乎只在真正的主力极端动作时才触发
  • 它对应的是 P99（19.14%）的极限区，即"最强的那 1% 主动方向压倒性信号"

4.3.2 12% 是较显著但非极端的预警线

  • 有 6.69% 的 bar 能达到 ±12%，约每 15 根 bar 出现 1 次
  • 对应 P95（13.13%）附近，即"前 5% 的强信号"
  • 作为预警（捕捉早中期背离萌芽）合理：比主门槛更容易触及，起到"提前吹哨"作用

4.3.3 为什么 20% 而非 10% 或 15%？

  • 如果设成 ±10%（11.44% 的 bar 能达），会过于频繁触发，噪音太大
  • 设成 ±20%（0.93%），则只在最强时触发
  • 原引擎选 20% 是把"转向确认"钉在极端区，宁可错过 99% 的普通背离，只在最强 1% 出手

4.4 用数据检验 07:10 的实际情况

07:10 的 |Δ占比| = 3.30%（5m）、2.35%（30m），处在 P50-P60 的常规区（中位数 4.23% 附近）——完全是普通水平，远未到 P95 的 12% 预警线，更别说 P99 的 20%。

所以 07:10 判 Neutral 是绝对正确的：它的 delta 方向强度只是"普通的一天"，不是背离级别的极端信号。

4.5 诚实结论与建议

  1. 20% 保留：有统计支撑（对应 P99 极值），作为主准入完全合理，且是系统既有设计。
  2. 12% 需严谨对待：这是在方案 C 里选的，统计显示它对应 P95（前 5%）。作为预警/加分是合理的（不应触发准入，只提示"接近背离"），但它不是 100% 确定的最优值。
  3. 可再优化的方向：
    - 用回测（背靠背测试各阈值下的信号命中率）选最优 delta_ratio 门槛
    - 或用分位数锚定（如 P90=10.5%、P95=13.1%）而非拍脑袋
    - 现在 12% 恰好接近 P95，是巧合的合理，但值得用回测确认

4.6 总结

20% 是系统原值（P99 极值区，有统计合理性）；12% 是新设的低门槛预警（缺回测，但统计显示它落在 P95 附近，作为预警线合理）。2026-09-08 的 07:10 数据在 P50-P60 常规区，所以 Neutral 判定正确。

五、可推导的正统 Orderflow 指标（从 DOM 快照）

已有的 3 个量化信号（量价背离、盘口大翻转、密集冰山）是方向性终端信号。而 DOM 底层 snapshots（逐 500ms 的 bids/asks 档位深度）和 tick 成交流（tick_trades）还能推导出一批更高维、更正统的 orderflow 分析数据。

5.1 从已算聚合值即可推导（立即可用）

5.1.1 买卖压力比 (Bid/Ask Pressure Ratio)

已经有的 early_book_ratio=0.95、late_book_ratio=1.21 可进一步导出：
- 全程 Book Ratio：近端买总量/近端卖总量的 5m 均值，衡量整体挂单攻防强度
- Book Ratio 标准差：衡量锚定稳定度（若 std 大，说明盘口深度剧烈摆动 = 不稳定）
- Ratio 拐点：early→late 是否穿越 1.0（从偏空转偏多）—— 07:10 是 0.95→1.21 穿越 1.0，正是"买盘接管"标志

5.1.2 订单流不平衡斜率 (Order Flow Imbalance Slope)

已有的 imb_momentum=+0.047（late-early）可正统化导出：
- w_imb 的 5m 斜率（线性回归）而非仅早/晚两点差值，更抗噪
- 近端/中端/深端各自的动量（imb_near_mom / imb_mid_mom / imb_deep_mom）—— 区分"哪一层在变"

5.1.3 做市商被动单占比 (Passive Flow Ratio)

从 absorption_bull/bear + stack_bid/ask 可导出：
- 被动吸收强度：absorption(吸收) 除以 stack(堆单)，衡量主动单被吞 vs 挂单堆积的比例
- spoof 占比：spoof/(spoof+stack)，衡量"假单 vs 真单"含量

5.1.4 微观流动性深度 (Micro Liquidity Depth)

已有的 imb_near/mid/deep + vacuum 可导出：
- 有效深度 (Effective Depth)：Near_Size + Mid_Size 的两侧净额（Bid-Ask），衡量真实可成交量（区别于名义挂单）
- 流动性质量：1/(vacuum 占比)，vacuum 越高流动性越差

5.2 需要返回底层 snapshots 数据（小改造即可）

5.2.1 价格-深度曲线 (Depth-Price Profile)

正统 orderflow 的核心。用每档 bids/asks 深度 vs 距离现价的档位，画出：
- 净深度累积曲线：从现价向外，Bid-Ask 净深度的累积积分。曲线越陡的档位 = 越强的墙体

  • 墙的坚挺度：墙档位在窗口内被消耗后是否回补（已有冰山 refill 逻辑可复用）

- 撤单-成交比 (Cancel-to-Trade ratio)：撤单次数/成交次数，衡量虚假流动性 vs 真实成交

六、三大 Orderflow 指标使用指南（Order Wall / Delta 足迹 / 撤单比）

6.1 Order Wall 净深度累积曲线（最核心）

6.1.1 是什么

从现价向外（上下各若干档），把每一档的净深度（Bid−Ask）逐档累加，画出一条"净深度随距离变化"的累积曲线。它回答："价格真要突破到某个位置，需要吃掉多少对手盘？"

6.1.2 怎么算

每档净深度_i = Bids_i − Asks_i；累积净深度_k = Σ(从1到k的每档净深度)。当累积净深度在某档急速转正（尤其左右落差大）= 该位置有硬墙。

6.1.3 07:10 实测解读

imb_near=+0.023 / imb_mid=-0.023 / imb_deep=-0.150，说明：
- 近端 5 档：净偏多（买>卖）
- 中端 6-20 档：微偏空
- 深层 21-120 档（≤30点内）：明显偏空 −0.150

累积曲线会显示：近端有买墙但偏薄，深层/30点内卖墙偏厚 → 意味着价格往上推会先吃到近端买墙（支撑），但下方深处卖墙重 → 上方空间受限。

6.1.4 怎么用（期权卖家视角）

读出 交易含义
现价上方累积净深度陡增转负 上方有卖墙 → 不宜卖 Call（会被逼仓），考虑 Bear Put Spread
现价下方累积净深度陡增转正 下方有买墙 → 可安全卖 Put（有支撑垫）
近端薄、深层厚 短期波动大但空间有限 → 适合卖铁鹰 / 卖价差收权利金
曲线平缓（无墙） 空间开放 → 单边方向可能延续，慎卖裸卖

对期权卖家：要找的是"价格离硬墙有足够保护距离"的位置。净深度累积曲线帮你定位真正的墙（不是只看 Wall strike 单点），从而选离墙最远、最安全的 sell 位置。

6.2 Delta 足迹（Footprint / Delta Profile）

6.2.1 是什么

每个价格档位上，主动买卖量的分布。看"价格是在哪一层被大量成交"。主动买（ASK 成交）= 打卖方的市价买；主动卖（BID 成交）= 打买方的市价卖。

价格档位  |  主动买量  |  主动卖量  |  净Delta
 7690      |   300     |   80      |   +220
 7685      |   500     |  150      |   +350  ← 低点附近的主动买聚集

6.2.2 怎么算

把 tick_trades（每笔成交流的 side、成交档位）按价格分档累加主动买/主动卖。已有 had_buy/had_sell 的 500ms 布尔数组，稍作扩展即可得到分价位的净 Delta。

6.2.3 07:10 实测解读

last_5m_delta=+668、price=-5.50（价格在跌但净Delta为正）—— 这正是主动买在低档位聚集的迹象：
- 价格跌到 7684.5 附近时，主动买量 > 主动卖量 → 低位有承接
- 低点附近被大量主动买单接住（不是被动挂单，是主动市价买）

6.2.4 怎么用（期权卖家视角）

读出 交易含义
低档位净Delta大量为正 底部有主动吸筹 → 卖 Put 有安全垫
高档位净Delta大量为负 顶部有主动派发 → 卖 Call 有安全垫
净Delta在某价位由负转正 该价位是吸筹/派发切换区 = 关键支撑/阻力
净Delta均匀→无聚集 无明确共识 → 暂缓单边卖，等确认

对期权卖家：Delta 足迹帮你找"买卖共识聚集的价格（体积顶/底）"。在这些价位附近卖价差（Otm 方向），能最大化时间价值而离高成交区有保护。

6.3 Cancel-to-Trade Ratio（撤单-成交比）

6.3.1 是什么

撤单次数 ÷ 成交次数。它衡量"盘口里多少是假单（虚假流动性）vs 真实成交"。这是识别 spoofing（幌骗）的核心工具。

6.3.2 怎么算

已有 spoof_bid=22 / spoof_ask=4（撤单次数）和 had_buy/had_sell（成交）。但更正统是：

Cancel-to-Trade Ratio = (买方撤单 + 卖方撤单) / (主动买成交 + 主动卖成交)

  • 1.0：盘口大部分是假单（挂单撤得多、成交少）→ 方向不可信

  • <0.5：盘口大部分是真实成交 → 方向可信

6.3.3 07:10 实测解读

spoof_bid=22 / spoof_ask=4，而 07:05-07:10 成交量 20248 手。即便只是撤单计数，买方撤单 22 次远超卖方 4 次，说明买方在反复挂单撤单（假托单诱多嫌疑高）。

6.3.4 怎么用（期权卖家视角）

读出 交易含义
买方撤单比高 假托单诱多 → 谨防冲高回落 → 别追买，上方卖Call可以但要注意
卖方撤单比高 假压单诱空 → 谨防探底回升 → 别追卖，下方卖Put可以但要注意
撤单比整体高 盘口充满虚单 → 方向信号打折，仓位放小
撤单比低（成交为主） 方向真实可信 → 可正常按信号建仓

对期权卖家：Cancel-to-Trade Ratio 是信号的"可信度校验器"。当背离/翻转信号出现时，先看撤单比：撤单比低 → 信号可信 → 正常卖价差；撤单比高 → 信号可能被幌骗污染 → 降低仓位或等撤单减少。

6.4 三指标组合决策流程（入场模板）

1. 用 Delta 足迹 → 找到买卖共识聚集的关键价位（支撑/阻力）
2. 用 Order Wall → 确认该价位上方/下方是否有硬墙、离现价多少点
3. 用 Cancel-to-Trade → 校验当前信号是否可信
↓
第1步 + 第2步 → 选出离硬墙保护最远的卖点（sell side 选有墙支撑的方向）
第3步 → 决定仓位：撤单比低 → 正常仓；高 → 缩仓

6.5 07:10 综合示例

  • Delta 足迹：低位 7684.5 附近主动买聚集（净Delta正）→ 下方有吸筹
  • Order Wall：近端买墙薄、深层卖墙重 → 上方空间受限
  • Cancel-to-Trade：买方撤单 22 次（假托）→ 信号可信度打折

结论：底部有承接但上方受限 + 假托单嫌疑 → 不宜激进追多，若做卖家可选离 7684.5 有保护的 Bull Put Spread（有低位吸筹垫底），但缩仓（因撤单比显示可信度一般）。这正是引擎判 Neutral 的合理性——信号存在但不够干净，保守观望。
