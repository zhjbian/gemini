修复 1：点击「1 files edited」无法折叠文件列表（真 bug）

根因（从压缩后的 kl() 函数读出）

let S = Me(e.document,"div","changes-detail");
S.append(header);
let x = r ? n.files : n.files.slice(0,3);   // ← r 只控制"显示几个"
for (let C of x) S.append(Hg(e,C));
if (!r && n.files.length > 3) { ...显示 "Show N files" 按钮... }
t.append(S)                                  // ← 列表**永远被 append**

changes-detail 无论展开还是折叠都会被渲染，r（展开态）只决定"显示前 3 个还是全部"。所以：

  • 文件数 ≤ 3 时（例如 1 files edited）：slice(0,3) 和全部结果相同，且 1 > 3 不成立（没有 Show more 按钮）→ 点击摘要行完全没有任何可见变化。这就是 bug 本身。
  • 文件数 > 3 时才有可见效果（3 个 ↔ 全部）。

修复（1 处、净增 32 字符）

- }t.append(S)};return{update:c=>{
+ }S.classList.toggle("hidden",!r),t.append(S)};return{update:c=>{

利用扩展自带的 .hidden { display: none !important; }（chat.css:55）：

  • 折叠（r=false）→ 整个文件列表隐藏 ✓
  • 展开（r=true）→ 显示全部文件 ✓

现在点击摘要行在任意文件数下都有实际效果（1 个文件也能收起/展开）。

附带行为变化：折叠时连 "Show N files" 按钮一起隐藏了 —— 但摘要行本身就能展开全部，所以这个按钮变得多余。node --check 通过。

修复 2：注入 CSS 隐藏整张卡片

media/chat.css 末尾追加：

/* ===== BBT local patch (start) =====
 * 隐藏 "N files edited" 变更卡片。
 * 这是对第三方扩展本体的临时补丁, **扩展升级会被覆盖**。
 * 想恢复: 删除本段, 或执行 `mv media/chat.css.bbt-bak media/chat.css`
 */
.changes-bar { display: none !important; }
/* ===== BBT local patch (end) ===== */

已核实补丁确实会生效

  • 扩展宿主通过 asWebviewUri(... media/chat.css) 加载该 CSS（dist/extension.cjs 的 html()），chat.js 同理来自 dist/webview/chat.js ✓
  • CSS 未内联在 extension.cjs（那里只有 <div id="changes-bar" class="changes-bar hidden"> 模板），.changes-bar { 规则只存在于 media/chat.css ✓
  • CSP 为 style-src ${cspSource} 'nonce-...'，放行该外部样式表 ✓

⚠️ 两者的关系

修复 2 会盖过修复 1 的视觉效果 —— 卡片被整体隐藏后，折叠与否都看不见了。之所以两个都做：

  • 你现在彻底看不到那张卡片（诉求）；
  • 若哪天想恢复（例如想用里面的 Undo / Review），只要删掉 CSS 那段，卡片回来时折叠功能也是好的（修复 1 生效）。

风险提示（你已确认接受）

  1. 扩展升级会覆盖这两个补丁（升级后需重打 → 用下面的脚本）。
  2. 修改的是第三方扩展本体，VS Code 可能提示扩展已被修改。
  3. 长期方案是向作者提 feature：加一个 deepseekHarness.showChangesBar 配置项 —— 这样就不用打补丁了。

一键重打补丁脚本

扩展升级会把文件替换回原始版本，所以补丁需要重打。脚本已放在项目里，升级后执行一次即可。

路径：scripts/repatch_vscode_changes_bar.py

特性

  • 幂等：已打过就跳过，不会重复注入（重复打补丁不会破坏文件）。
  • 版本自适应：自动从 aria-expanded",String(<VAR>) 与 let <VAR>=Me(e.document,"div","changes-detail") 抓取变量名，抗压缩改名；不像硬编码字符串那样一升级就失效。
  • 自动备份：仅在文件尚未打补丁时创建 .bbt-bak（备份里始终是原始版本）。
  • 自动校验：打完用 node --check 验语法，并回读确认两处补丁确实生效。
  • 可还原：--revert 从备份恢复。
  • 可只修折叠：--no-hide 保留卡片可见但修复折叠 bug。

用法

# 打补丁（幂等；扩展升级后执行这一条即可）
python3 scripts/repatch_vscode_changes_bar.py

# 只检查不改动
python3 scripts/repatch_vscode_changes_bar.py --dry-run

# 只修折叠 bug，保留卡片可见
python3 scripts/repatch_vscode_changes_bar.py --no-hide

# 从 .bbt-bak 还原原始文件
python3 scripts/repatch_vscode_changes_bar.py --revert

# 补丁全部版本目录（默认只打最新版）
python3 scripts/repatch_vscode_changes_bar.py --all

补丁逻辑（脚本核心）

ALREADY_JS_RE = re.compile(r'\w+\.classList\.toggle\("hidden",!\w+\),t\.append\(')

def patch_js(text: str):
    if ALREADY_JS_RE.search(text):
        return text, "already"
    # 文件列表容器变量：let <VAR>=Me(e.document,"div","changes-detail")
    m = re.search(r'let\s+(\w+)\s*=\s*Me\(\s*e\.document\s*,\s*"div"\s*,\s*"changes-detail"\s*\)', text)
    if not m:
        return text, "anchor-missing"
    list_var = m.group(1)
    # 展开态变量：aria-expanded",String(<VAR>)
    mr = re.search(r'aria-expanded"\s*,\s*String\((\w+)\)', text)
    expand_var = mr.group(1)
    # 在该容器首次出现之后，找到 `t.append(<LIST_VAR>)`
    ma = re.compile(r'([;},])t\.append\(\s*' + re.escape(list_var) + r'\s*\)').search(text, m.end())
    insert_at = ma.start() + 1
    injected = f'{list_var}.classList.toggle("hidden",!{expand_var}),'
    return text[:insert_at] + injected + text[insert_at:], "patched"


def patch_css(text: str):
    if "BBT local patch (start)" in text:
        return text, "already"
    return text.rstrip("\n") + "\n" + CSS_BLOCK, "patched"
