二、 Adam Set 四大核心特征实战有效性量化检验

1. 多梯队挂单失衡 (Multi-Tier Imbalance: Near 50% + Mid 35% + Deep 15%) ★★★★★

  • 理论原理: 摒弃过去单一 10 档失衡，近端 Top 5 档代表瞬时碰撞阻力（50%），中端 6-20 档代表 5 点作战区间（35%），深层 20-200 档代表 50 点战略大局（15%）。
  • 实战验证案例 (8/31 06:45):
    • 近端 Top 5 档失衡度 imb_near: +0.357，加权失衡度 weighted_imbalance: +0.278；
    • 动量加速度 imb_momentum: +0.152，显示买盘挂单厚度在后 2.5 分钟呈爆发式增厚；
    • 有效性评价: 成功提前捕捉到底部买方限价垫盘意图，直接给出 Consensus: Bullish 判定，领先于市价激进买单的出现。

2. 挂单堆叠与防线加固 (Stacking Defense) ★★★★★

  • 理论原理: 当主力在关键支撑位真实加仓防御时，500ms 增量 diff_bids > 50 频次显著超过卖方，构筑稳固防线。
  • 实战验证案例 (8/31 07:40 见底反转信号):
    • 研判记录直接引用: “空头于 7674.75-7676.75 区域砸盘衰竭，主动买盘快速接管... DOM 显示买方重度筑墙防御（58次:10次）”；
    • 有效性评价: 大单在 7675 附近以近乎 6:1 的压倒性频次连续加固堆叠买单，构筑出日内绝对铁底，此后 ES 展开强劲反弹，验证极度精准。

3. 梯级冰山吸收体系 (Tiered Passive Iceberg Absorption) ★★★★★

  • 理论原理: 将吸收划分为「极致冰山死守 <=1.0点」、「主流波段吸收 <=3.0点」与「广义拦截 <=5.0点」，攻克“正 Delta 误判为拉升”的传统死穴。
  • 实战验证案例 (8/31 06:35 / 07:10 高位诱多拦截):
    • 研判记录: “在 7700.00-7701.25 关键阻力带遭遇机构密集看空冰山单被动吸收，正 Delta 下价格急跌 -9.75 点”；
    • 有效性评价: 成功识别出主力在 7700 关口利用市价买盘高位派发、暗中挂限价大单压制的真实意图，直接拦截了追多信号，定性为空头主控。

4. 流动性真空 (Liquidity Vacuum) ★★★★★

  • 理论原理: 当近端单档挂单量降至个位数 (< 10 手) 时，挂单极度稀薄，极易引发逼空暴涨 (Squeeze Up) 或破位下杀 (Breakdown)。
  • 实战验证案例 (8/31 06:45 逼空拉升):
    • 哨兵引擎直接触发: DOM 5m卖方真空逼空触发 (VacuumAsk=147.0s, ImbNear=+0.357, Momentum=+0.152)；
    • 有效性评价: 上方卖单真空持续长达 147 秒，市价买单仅需少量成交即可推升价格，精准预言了随后的跳跃式逼空拉升。

三、 实战暴露的技术短板与工程加固方案 (Identified Gaps)

1. Java 端 GZIP 多次追加写入产生的多重头 (Duplicate Stream Headers)

现象: 9/01 与 9/02 的 DOM.csv.gz 文件头部存在两个连续的 1f 8b 08 gzip 魔数（共 20 字节），导致标准解压工具与 Python 原生 gzip.open 报错 Error -3 while decompressing data: invalid block type，导致 9/01~9/02 的 DOM 实时扫描中途降级为纯 Tick 计算。
修复方案: 在 Python 端 safe_read_csv 中加入自适应跳过前导 10 字节冗余头逻辑；在 Java 导出器中优化 reopen append 流程，仅在新建文件时写入头信息。

2. 单日 400 万行大文件跨度扫描的性能瓶颈

现象: 200 档深度单日产生约 400 万行数据，盘中 5m 哨兵若从头解压扫描至 11:30 PST，耗时会由 1 秒上升至 15~25 秒。
修复方案: 建立基于小时（Hourly Offset Index）的跳表缓存，使盘中 5m 哨兵直接从当前小时的字节偏移量切入，保证亚秒级（< 500ms）高速响应。
