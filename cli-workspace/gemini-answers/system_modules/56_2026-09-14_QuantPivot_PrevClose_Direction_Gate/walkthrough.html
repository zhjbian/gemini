机制 ②「QuantPivot边界反向」前置条件 ③「昨收方向」· 验收报告

2026-09-14 · 归档 56_2026-09-14_QuantPivot_PrevClose_Direction_Gate

用户指令：「H1: 只有 H1 高于昨天收盘价时才能开空仓；L1: 只有 L1 低于昨天收盘价时才能开多仓」
同日口径澄清（已据此修订）：「昨收方向 只适用于 H1 和 L1，不适用于 H2 和 L2」
关联事故：账本第 5 笔（DB id 238/239）BEAR_CALL_SPREAD 764/766， 08:41:50 触发、08:44:16 止损，$-14.00 / 腿（LIVE）。

1. 事故 → 根因 → 修复

环节内容
现象大幅低开日（昨收 764.29 → RTH 开 759.00），机制 ② 在 H1 = 761.53 自动布防并触发 卖 Call 做空，3 分钟内被反弹打穿 2.20× 硬止损。
根因H1/H2 是「以当日 RTH 开盘为锚 + 平均上行扩张」的相对阻力；低开日阻力带可整体落在昨收之下。旧判据只查「波幅 / 日内位置 / 容差带」，无任何「相对昨收的绝对位置」方向保护 ⇒ 在缺口回补（向昨收回归）的必经路径上逆势站空。
修复新增前置条件 ③「昨收方向」（仅 H1 / L1）：做空 H1 要求 H1 > 昨收、做多 L1 要求 L1 < 昨收；H2 / L2 豁免。判据在已判定档位（qp_level）之后执行 ⇒ H1 / L1 档位的 QUALIFIED 与 ARMED 两路径同时被拦；触发侧兜底复核；只读探针新增判据行（含适用性标注）。

真实数据佐证（只读复算）

prev_close (2026-09-11 RTH Close) = 764.29
2026-09-14 RTH Open               = 759.00        ← 低开 −0.69%
H1 = 761.53   H2 = 764.28   L1 = 756.50   L2 = 754.81
⇒ H1 (761.53) < prev_close (764.29)   →  事故单档位 = H1  →  新规则判定「禁止开空仓」
⇒ 事故单 238/239（trigger_price = H1 = 761.53）今日即可被拦

2. 实现要点（档位级 · 单一权威 · 三层落地）

层改动
数据层
pivots/quant_pivot.py		 在既有 30 日样本 hist_days（date_str < target_date，升序）上取上一交易日收盘：
prev_close = float(hist_days.iloc[-1]['Close'])，写入两条 return 路径。⇒ 与 H1/L1 同源同口径，不做「平台昨收 vs 计算昨收」两套数字。
判定层
option_seller_engine.py		 纯函数 check_qp_prev_close_direction(level, quant_pivot)：
· H1 ⇒ 要求 H1 > prev_close（applicable=True）；
· L1 ⇒ 要求 L1 < prev_close（applicable=True）；
· H2 / L2 ⇒ N/A（放行，applicable=False）；
· 适用档位缺数据 ⇒ fail-closed + data_missing=True。
机制 ② 上/下轨先判定档位（qp_level = 'H2'|'H1' / 'L2'|'L1'），再以 qp_level 为入参校验，并作为 QUALIFIED / ARMED 的合取条件： if _pc_ok_h and is_testing_or_above_h1: … elif _pc_ok_h and dist_to_h1 > qp_tol: …
⇒ H2 做空 / L2 做多天然放行；H1 / L1 档位的两条 return 都在分支内，天然同时被拦。
触发侧兜底
option_seller_manager.py		 条件单触发路径在既有「② 多次开仓三维准入」之后再校验同一前置（入参为解析出的 qp_level）；不通过 ⇒ 落 SKIPPED_GUARD 事件且不消费 pending。覆盖：热重载 / 重启前遗留的 PENDING 单 + 跨进程重取的 QuantPivot。H2 / L2 单由纯函数返回 N/A ⇒ 一律放行。
可观测
intraday_probe.py		 探针 _mech_counter_trend(..., 'QP') 新增判据行「前置③ 昨收方向（做空：H1 > 昨收 · 仅 H1 档位适用）/（做多：L1 < 昨收 · 仅 L1 档位适用）」；按引擎同口径做档位代理（现价 ≥ H2 − 0.2 / ≤ L2 + 0.2），给出 prev_close_ok（有效值）与 prev_close_applicable，并纳入 side_pass。
适用范围：本项仅适用于机制 ②「QuantPivot边界反向」（RANGE_BOUND_UPPER_BOUNDARY / RANGE_BOUND_LOWER_BOUNDARY）； 机制 ④「趋势日极限终点」沿 SPX Gamma 墙开仓，不受本项约束。

5. 行为变化摘要（对使用者）

场景旧行为新行为
大幅低开日（H1 ≤ 昨收）现价触及 / 逼近 H1卖 Call 做空（直接开仓或布防）拦截（REJECTED + veto_reasons）
大幅低开日现价进入 H2 档位（即便 H2 ≤ 昨收）卖 Call 做空完全不变（H2 豁免）
大幅高开日（L1 ≥ 昨收）现价触及 / 逼近 L1卖 Put 做多（直接开仓或布防）拦截（严格反向对称）
大幅高开日现价进入 L2 档位（即便 L2 ≥ 昨收）卖 Put 做多完全不变（L2 豁免）
正常日 / 缺口已收复（H1 > 昨收 且 L1 < 昨收）原逻辑完全不变
机制 ④ 趋势日极限终点沿 SPX Gamma 墙完全不变（不受本项约束）
