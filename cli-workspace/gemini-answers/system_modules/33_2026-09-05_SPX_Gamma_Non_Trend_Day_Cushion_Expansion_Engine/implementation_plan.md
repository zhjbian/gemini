# SPX Gamma 非趋势日顺势 Cushion 空间动态拓宽引擎实施计划

## 问题背景与诱因剖析
在原有的 SPX Gamma 5分钟周期决策树体系中，顺势推进（Bullish:Bullish 或 Bearish:Bearish）的安全缓冲（Cushion）采用固定门槛值 `15.0 点`：
- 在 2026-09-04 09:20:00，SPX 现价报于 7724.91，Call Wall 位于 7740.00，上方剩余空间为 `7740.00 - 7724.91 = 15.09 点`；
- 因为 `15.09 点 >= 15.0 点`，系统满足了顺势看多的充盈空间条件，输出 `Bullish:Bullish`；
- **微观物理与实际走势矛盾**：对于非单边强趋势日（Non-Trend Day，如区间宽幅震荡、早盘单边下探 44 点后的超跌死猫反弹），标的在做市商正 Gamma 阻尼压制与现货买盘枯竭下，极难触及最外层最大 Gamma 阻力墙。实际上，SPX 在 09:50 反弹至 7728.23 处便耗尽动能再度大幅下挫，09:20 的看多研判成为危险的诱多陷阱。

## 升级目标与架构设计
1. **纯粹价格量化识别日内形态模式（Trend Day Regime Detector）**：
   - 坚决遵循 SPX Gamma 模块内部判定物理独立性铁律，不引入外部均线与技术指标；
   - 纯粹基于美西时间 06:30 RTH 开盘价、日内最高价、最低价与现价相对位置，客观量化判定当前是否属于真正的单边强趋势日：
     - **单边多头趋势日 (`is_bullish_trend_day`)**：现价高于开盘价 >= 5点，开盘后未曾深幅下破 (破位 <= 8点)，且距日内最高回撤未超 15点；
     - **单边空头趋势日 (`is_bearish_trend_day`)**（双向严格对称）：现价低于开盘价 >= 5点，开盘后未曾冲高 (冲高 <= 8点)，且距日内最低反弹未超 15点；
     - **非趋势日 (`Non-Trend Day`)**：不满足上述严苛特征的所有行情（震荡、反弹、冲高回落）。
2. **顺势推进 Cushion 门限自适应动态分级**：
   - **趋势日 (Trend Day)**：维持宽松顺势门槛 `Cushion >= 15.0 点`；
   - **非趋势日 (Non-Trend Day)**：将顺势空间门槛硬性从 15.0 点**提高至 23.0 点**！
   - 一旦非趋势日 `Cushion < 23.0 点`（如 09:20 的 15.09 点），一律一票否决顺势推进，降级拦截为 `Neutral:Compression-Top`（上行空间压缩中性）或 `Neutral:Compression-Bottom`（下行空间压缩中性）。
3. **风控指令与提示文案深度融合**：
   - 在 `trend_logic`、`risk_advice` 与判词 `verdict` 中清晰注明当前形态分类（单边趋势日 vs 非趋势日）以及对应 Cushion 阈值（15点 vs 23点），为期权卖方提供精准风控指引。
