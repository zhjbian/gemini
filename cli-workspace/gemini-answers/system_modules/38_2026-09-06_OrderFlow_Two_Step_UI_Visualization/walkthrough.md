# 订单流两步法（方向准入判定与底层强度打分）展开详情卡片UI重构交付与验收报告

## 1. 交付概况
- **对应模块**: 38. 订单流两步法（方向准入判定与底层强度打分）展开详情卡片 UI 组件重构与实时数据判据校验
- **归档时间**: 2026-09-06
- **核心成果**:
  1. **保留既有 4 大基础卡片与 DOM 微观卡片**:
     - `Recent 5-Min Micro` (5分钟微观切片对比表)
     - `Recent 30-Min Metrics` (30分钟关键指标与吸收频次)
     - `RTH Cumulative` (常规交易时段累计进程表)
     - `PM Metrics` (盘前指标与进程表)
     - `Adam Set DOM Micro-Structure` (深度多级盘口失衡、撤单闪烁、堆单防御、冰山单检测卡片)
  2. **追加核心第 1 步 UI 卡片：基本规则方向准入判定 (Direction Qualifying Rules)**:
     - 对应系统规则手册《第 3 章：第一步：基本规则方向准入判定》；
     - 顶部方向徽章与当前触发规则指示横幅；
     - 前置过滤与一票否决红线（Price Position 红线防追高杀跌、Spoofing 虚假诱多诱空红线、机构大单/趋势日反向阻断护盾）；
     - 三大高胜率 Setup 状态矩阵卡片（Setup 1 极值反转吸收吞没 Gate 1 & 2、Setup 2 趋势日10m双柱回踩 Gate 1 & 2、Setup 3 顺势价值区突破 Gate 1 & 2），展示实时测量值与规则阈值对比，并在达成时高亮浅绿/浅红徽章。
  3. **追加核心第 2 步 UI 卡片：底层数据强度打分体系 (Strength Scoring 1 ~ 10 分)**:
     - 对应系统规则手册《第 4 章：第二步：底层数据强度打分体系》；
     - 强度得分大数字徽章 (例如 `7 / 10 分`)、等级徽章 (`High` / `Medium` / `Low` / `Neutral`)、多阶颜色渐变进度条；
     - 打分公式实时明细：`基准起跑分 + 满足底层加分项 = 最终强度得分`；
     - 9 大客观底层特征加分项清单表（Delta 绝对主导占比、Cumulative Delta 爆发突破、反向冰山被吃穿、主动大单占比超过阈值、多空动量极值延续等），动态比对实时数据，明确标记 `+1分 达标 (MET)` 或 `0分 未达标`。
  4. **设计规范与设计准则遵循**:
     - 严格遵循浅色主题 (Light Theme)，采用白底 `#ffffff`、柔和边框与清爽背景，无任何大面积深色背景；
     - 所有数学计算与物理公式均采用纯文本格式，严格规避 LaTeX 渲染乱码；
     - 静态资源更新版本控制缓存 (`bbt_signals.js?v=1.2.28`)。
