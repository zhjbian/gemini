# 单边强趋势日 (Trend Day) 判定规则重构与阈值优化实施计划

## 1. 业务背景与问题定义
在现有量化交易系统（包括 `PyTools/quantdata/trend_regime.py`、`order_flow_rules_optimizer.py`、`bbt_signals` 网页端）中，SPY 单边强趋势日采用了以 RTH 开盘价为硬基准且极值容忍度过紧（回撤 <= 1.50点，破位 <= 1.20点）的判定模型。

这导致两类严重假阴性误判：
1. **盘前拉升/下挫脱离导致开盘基准失真**：当标的在盘前已有明确方向并形成全天最低/最高点时，RTH 开盘价已处于半山腰，继续要求脱离开盘价 >= 0.80 点导致单边趋势识别滞后；
2. **正常趋势回踩被过早否决**：日内单边强趋势通常伴随 1.5 ~ 2.0 点的健康回踩（对应 SPX 15~20点），原 1.50 点的最大回撤容忍阈值和 1.20 点的开盘破位阈值过于严苛，将健康顺势日（如 2026-09-03 07:40:00）错误归类为常规震荡日，致使 Setup 2（趋势日 10m 双柱回踩重燃）策略无法激活。

## 2. 规则调整设计与量化判据对比

| 维度 | 旧规则判据 (Legacy) | 新规则判据 (Refactored) | 量化与交易内涵 |
| :--- | :--- | :--- | :--- |
| **多头脱离基准** | `current_spy >= rth_open_spy + 0.80` | **`current_spy >= full_day_low + 0.80`** | 脱离基准改为**全天低点**（包含盘前 Pre-Market 与 RTH），准确反映标的自全天底部的实质性推升幅度。 |
| **空头脱离基准** | `current_spy <= rth_open_spy - 0.80` | **`current_spy <= full_day_high - 0.80`** | 严格镜像对称，脱离基准改为**全天高点**（包含盘前 Pre-Market 与 RTH），反映标的自全天顶部的实质性下杀幅度。 |
| **开盘破位/冲高容忍** | `(rth_open - rth_low) <= 1.20`<br>`(rth_high - rth_open) <= 1.20` | **`<= 2.00 点`**<br>(对应 SPX 20.0 点) | 将开盘初段的最大容忍破位/反抽从 1.20 点放宽至 2.00 点，吸收开盘 30 分钟的价格噪声。 |
| **极值回撤/反弹容忍** | `(rth_high - current) <= 1.50`<br>`(current - rth_low) <= 1.50` | **`<= 2.00 点`**<br>(对应 SPX 20.0 点) | 将高位回撤/低位反弹最大容忍度从 1.50 点放宽至 2.00 点，允许标的完成健康的均线带回踩测试。 |
| **均线带单边约束** | 5m 收盘反向 15m 13EMA <= 1 次 | **5m 收盘反向 15m 13EMA <= 1 次** | 维持不变，确保中周期均线带单边压制或支撑真实有效。 |
