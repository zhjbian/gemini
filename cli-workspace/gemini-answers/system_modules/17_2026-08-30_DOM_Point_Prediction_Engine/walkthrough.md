# 基于深度 DOM 200 档与 Delta 效率的日内顶底预判引擎验收报告 (Walkthrough)

## 一、 变更概述

根据 YouTube 顶级专业交易员 DOM 读盘实战与 Adam Set 日内顶底预判机制，我们对现有的订单流特征生成器与 AI 研判决策链路进行了重要升级：
1. **废弃单一激进的 <=1.0 点限制**，重构为具备多空双向对称性与微观鲁棒性的**梯级冰山吸收识别体系**：
   * **极致冰山 (Extreme Pin / Wall)**：`Abs(Price_Change) <= 1.0` 点，极高置信度单档死守；
   * **主流波段吸收 (Standard Churn / Absorption)**：`Abs(Price_Change) <= 3.0` 点，主流基准，兼顾 2-3 点微观换手区间；
   * **广义拦截 (Broad Absorption)**：`Abs(Price_Change) <= 5.0` 点，捕获动能衰竭准备区。
2. **引入 DPER (Delta-Price Efficiency Ratio)**：
   * 量化每 1000 手 Delta 推动的价格变动点数；当 DPER 归零且伴随巨量换手时，确证主力被动吸收。
3. **AI Prompt 升级（顶底预判与关键点位研判法则）**：
   * 自动结合高位看跌冰山拦截位与上方挂单密集带输出 **`潜在阻力位 (Target High / Resistance)`**；
   * 结合低位看涨冰山吸筹位与下方筑墙密集带输出 **`潜在支撑位 (Target Low / Support)`**；
   * 标注单边击穿留下的流动性真空带（Vacuum Pockets / Zero Prints）作为反手交易的第一止盈目标。
