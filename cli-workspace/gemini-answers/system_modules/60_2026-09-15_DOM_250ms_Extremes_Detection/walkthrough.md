## 2. 为什么必须做（问题实证）

既有 DOM 指标**全部是窗口均值**（`imb_near = np.mean(imb_near_500ms)`）。均值对瞬时事件是低通滤波。实测（2026-09-14 ES）：

| 窗口 | DB（5 分钟均值） | 250ms 快照极值 | 倍率 |
|---|---|---|---|
| 08:05 | `imb_near` 均值 **+0.007** | **−0.5316** @ 08:05:30.000 | **76×** |
| 08:40–08:45 | **+0.043** | **+0.3634** @ 08:41:43.000 | 8.4×（出现在该笔亏损单入场前 7 秒） |

⇒ 均值口径**在结构上**无法发现毫秒级插针 / 瞬时撤单 / 挂单真空。

## 3. 检测机制（逐层说明）

### 3.1 网格与数据来源（与哨兵**同源**）

- 原始文件：`RAW_DATA_DIR/ES_<YYYYMMDD>_DOM.csv.gz`（`Timestamp,Type,Level,Price,Size,Contract`，每快照 ≈400 行 = 200 档 × 2 侧）。
- 快照节奏：**ES 自 2026-09-14 07:51:30 起 250ms**；此前与 NQ 相同 500ms。
- 网格间隔 `resolve_grid_interval_ms()` **跟随源**（ES 250 / NQ 500），不硬编码。
- **重构（单一权威）**：`load_dom_snapshots` / `build_dom_grid_series` / `map_trades_to_grid` 从哨兵内联代码**抽取为共享函数**，哨兵与 `dom_extremes` 调同一份实现 —— 避免"两处实现慢慢漂移"。

### 3.2 被检测序列与四类事件

序列：`imb_near` / `imb_mid` / `imb_deep` / `w_imb` / `near_bids`（近 5 档买盘合计）/ `near_asks`（近 5 档卖盘合计）。

| 类型 | 定义 | 参数（`order_flow_config.THRESHOLDS["dom_extremes"]`） |
|---|---|---|
| `outlier` | 稳健 z 超阈的**连续段**（允许桥接 1 格） | `k_mad=3.5`、`min_bins=1`、`max_gap_bins=1` |
| `step` | 相邻格近 5 档挂单量**跳变** | `step_vol=50`（**@250ms 基准，按间隔线性缩放**） |
| `flip` | `imb_near` 符号翻转 | `flip_thr=0.10`、`flip_max_bins=6` |
| `vacuum` | 单侧挂单真空段 | 由 `vacuum_bid/ask` 布尔序列导出 |

### 3.3 稳健尺度：窗口局部 `median/MAD`（含两次失败教训）

尺度链：**`MAD → IQR/1.349 → flat_floor(max(|median|×0.02, 1e-6))`**，**刻意不退回标准差**。

| 方案 | 结果 | 结论 |
|---|---|---|
| `MAD`，MAD=0 时退回 `std` | 平台型异常 z 仅 **1.46**（平台自己把 std 抬高） | ❌ 漏报 |
| `MAD`，退回 IQR/截尾 std | z 仅 **1.75**（≥15% 占比的平台污染尺度） | ❌ 仍漏报 |
| `MAD → IQR/1.349 → flat_floor`（**最终**） | 平台型异常被正确判出 | ✅；**持续/大幅异常交给绝对阈值**（`abs_imb_strong=0.30`、`abs_vol_strong=400`） |

### 3.4 数据有效性掩码 `data_valid_mask`（必须项）

网格 `range(start, end, interval)` 的**预热段**（早于第一根快照）与**尾部陈旧段**（晚于最后一根）若留零值，会被读成"挂单量 = 0 的极端异常"。
⇒ 只保留真实快照覆盖的格，其余置 `NaN` 并从统计中剔除。**修复效果**：07:30 窗口伪极值 **32 → 3**；`near_asks z=−17` 消失。

### 3.5 分级、形态、方向

- **分级**：L1（score ≥3）/ L2（=2）/ L3（≤1）；弱序列（`imb_mid` / `imb_deep`）计分 −1 且**结构性不进 L1**。标定：2026-09-14 08:00–09:00 的 score 直方图 `{0:19, 1:195, 2:191, 3:21, ≥4:0}` ⇒ 若 L1 门槛设 ≥4 则**恒空**，故取 ≥3。
- **形态按时长**（比按 z 高低更贴合用途）：`duration_ms ≤ 750` ⇒ `spike`（插针），否则 `plateau`（平台）。
- **方向**（`event_direction`）：失衡类按峰符号；`near_bids` 异常放大 ⇒ 多 / `near_asks` ⇒ 空；`step` **加单按该侧、减单取反**；`flip` 看翻转方向；`vacuum` 买侧⇒空 / 卖侧⇒多。

### 3.6 ★ 间隔归一（本轮发现并修复的口径缺陷）

**现象**：同一 `step_vol=50` 在 500ms 网格上比 250ms 网格**更易被跨越**（相邻两格之间累积了 2 倍挂单流）⇒ L1 密度跨日不可比（实测 08-31 **26 条/窗口** vs 09-14 **1 条/窗口**）。

**修复**：`analyze_arrays` 内 `step_vol_eff = step_vol × grid_interval_ms / 250`（挂单量变化随时长近似线性累积），**评分与检出一致使用该有效阈值**，并在结果中回传 `step_vol_eff`。效果：7 天总事件 **30,421 → 11,084**、入表行 **23,521 → 6,669**。已写成 4 条契约测试（250ms 用基准值、500ms 阈值 ×2、大 Δ 仍触发、显式覆盖同样归一）。

### 4.1 幂等与回滚

- 唯一键 `(event_date, ts_ms, kind, series, side)` + `INSERT … ON DUPLICATE KEY UPDATE`；
  `series` / `side` 取 **NOT NULL DEFAULT ''**（MySQL 中唯一键列含 NULL 可重复 ⇒ 幂等失效）。
- **实测幂等**：09-14 重复执行 → 行数 **525 → 525**（无新增）。
- **口径变更重建**：`--replace` 先删该批日期旧行再写（否则"被降级到门槛以下"的旧事件会残留）；`--revert-sql` 输出受影响主键的 `DELETE`（本次 6,669 条）。

### 4.2 页面与接口

- `GET /data/dom_extremes`：事件清单（含分组计数 `by_importance` / `by_kind` / `by_series`）+ **实时摘要** `live`（读最近一条 ES 信号的 `dom_metrics.extreme`）+ 免责声明。
- `/bbt_signals` 新增卡片「DOM 毫秒极值（250/500ms 快照级）」：级别筛选、跟随全局日期、只标注警示条；表头字段 = 时间 / 级别 / 类型 / 序列 / 方向 / 幅度 / z / 时长 / 形态·性质。

## 5. 前向验证（P3）

### 5.1 方法与口径

- 事件时刻 → 之前最近一根 5 分钟 bar 为入场价（**无前视**），前向 15 / 30 / 60 分钟，命中 = 收盘价按事件方向变动 > 0。
- 对照组 = 现网口径的 5 分钟均值信号（`imb_near` 均值符号，窗口结束触发），**同一套前向价格与时点口径**。
- 样本 = 7 个有 RTH DOM 数据的交易日（2026-08-31、09-04、09-07、09-08、09-10、09-11、09-14），入样事件 16,659 条。

### 5.2 结论

**入样事件 16,659 条样本（7 日 × 3 个前向）**，全部落在"无优势"区间：

| 分组 | 15m 命中 / 基准 / edge | 30m | 60m |
|---|---|---|---|
| **全样本** | 48.3 / 49.7 / **−1.4** | 49.2 / 51.0 / **−1.8** | 49.3 / 50.0 / **−0.7** |
| L1（最强级） | 46.2 / 49.0 / −2.8 | 49.3 / 51.3 / −2.0 | 47.4 / 49.9 / −2.5 |
| 对照组（现网 5 分钟均值） | 48.9 / 50.3 / −1.4 | 42.5 / 49.2 / **−6.7** | 48.3 / 50.1 / −1.8 |
| `outlier` \|z\|≥6 | 45.4 / 48.9 / −3.5 | 50.6 / 52.7 / −2.1 | 48.0 / 50.1 / −2.1 |
| `step` \|Δ\|≥200 | 49.2 / 49.8 / −0.6 | 49.1 / 50.0 / −0.9 | 50.1 / 49.9 / +0.2 |
| 共振（outlier+step ≤2s） | 47.5 / 49.1 / −1.6 | 49.2 / 51.3 / −2.1 | 49.4 / 49.8 / −0.4 |
| 买盘侧 `near_bids`（n 最大） | 50.0 / 50.0 / 0.0 | 47.6 / 48.5 / −0.9 | 49.6 / 49.8 / −0.2 |
| 被成交 `consumed` | 49.7 / 50.2 / −0.5 | 48.6 / 50.0 / −1.4 | 50.2 / 50.1 / +0.1 |
| 真撤单 `cancelled`（n=354） | 48.7 / 49.4 / −0.7 | 48.6 / 49.6 / −1.0 | 50.6 / 49.9 / +0.7 |
| ★ 候选子集（outlier·imb/w_imb） | 43.7 / 47.8 / −4.1 | 50.1 / 54.3 / −4.2 | 45.6 / 49.8 / −4.2 |

- **多空两侧一致地"无优势"**：BEARISH −2.5 / −3.0 / +1.7（n=2006/3807/3807）、BULLISH −0.1 / 0.0 / −4.1（n=1613/2713/2713）⇒ 不是"只对某一侧有效"。
- **强度不单调**：`|z|≥6` 的 edge（−3.5 / −2.1 / −2.1）**并不比** 3.5≤|z|<4（−0.4 / −3.5 / −4.1）更好 ⇒ "越极端越有效"**不成立**。
- 唯一正 edge 出现在 `imb_deep`（+8.2 / +11.4 / +4.2），但 **n 仅 22–29 条**，属噪声量级，**不作为结论**。
- 对照组（现网 5 分钟均值口径）同样是 −1.4 ~ −6.7 ⇒ 该时段 ES 的 06:35–11:30 形态**对这批微观信号整体不利**，而非毫秒极值独有。

**判定**：毫秒极值**是真实的**（数值/时刻可复现、与均值口径差 8–76 倍），但**不是方向性预测因子**。二者不矛盾 —— 它度量的是"盘口瞬时结构发生了剧烈变化"，而不是"价格接下来会往哪边走"。因此：

- ✅ 允许：标注、复盘归因（解释"为什么 5 分钟均值是 +0.007 而实际瞬时失衡 −0.53"）、事后审计（如 08:41:43 的 +0.36 出现在那笔止损单入场前 7 秒）。
- ❌ 禁止：作为开仓/平仓/方向判定依据；卖家系统与信号引擎**不读**该表。

### 5.3 统计方法两次修正（**必须记录**，否则会得出相反的结论）

| # | 缺陷 | 表现 | 修复 |
|---|---|---|---|
| 1 | 基准率**跨日取算术平均**后套到所有行 | 单边日基准极端（08-31 上行占比 98%）⇒ 出现「BEARISH 基准 1.9% / BULLISH 基准 98.1%」这种与事实无关的极端值，进而造出 **±50pp 的假 edge** | 基准率**逐日**计算并**逐行**取用（`base_per_day` 落档；报告新增 M 板块诊断） |
| 2 | `_base_up_pct` 误用 `f[2]`（Δ 数值，"有变动即真"） | 基准率恒 ≈93–100%，"趋势日假优势"控制**完全失效** | 改用 `f[3]`（方向命中布尔）；已加回归测试（单调下行 ⇒ 0%、单调上行 ⇒ 100%、锯齿 ⇒ 中间值） |

> 这两处都不是"实现细节"：修复前任何一个子集都能被算成"edge +20 ~ +50pp"。它们是本模块**唯一**可能让人误以为毫秒极值可交易的原因。

## 7. 已知限制与后续（据实）

1. **无方向优势**（主结论）：毫秒极值不能进决策；已按"只标注"落位。
2. **L1 密度仍随日波动**（08-31: 19 条/窗口；09-14: 0.75 条/窗口）—— 间隔归一解决了 250/500ms 之间的可比性，但**日内活跃度**差异仍在。若要让 L1 成为"每日最强 N 条"，需引入**活跃度自适应阈值**（例如按当日网格 Δ 的稳健尺度定标）或**当日分位**分级（注意分位法有轻微前视，需用盘中滚动分位替代）。
3. **08-31 价点仅 23 根**：该日基准率与 edge 置信度低，已在报告 M 板块暴露；
4. **部分交易日原始 DOM 损坏**（§5.4）：回填对不可读日期跳过并如实报 `no_snapshots`，不做插补；
5. **`order_flow_signals` ES 价格异常**（2026-09-14 比同日 `spx_gamma_signals` SPOT 高约 75 点）为既有数据问题，待另行复核；方向性研究不受绝对价位影响，但不可用于跨品种价格比较。
