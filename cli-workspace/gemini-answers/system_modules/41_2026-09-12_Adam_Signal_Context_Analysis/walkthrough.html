39. Adam 帖文信号上下文分析 (Adam Signal Context Analysis)

演进时间 2026-09-12 ｜ 归档目录 39_2026-09-12_Adam_Signal_Context_Analysis ｜ 技术栈: Python 3.11 / DeepSeek (OpenAI 兼容) / Gemini (保留通路) / Flask-SQLAlchemy / launchd / HTML Email

背景与目标

  • 用途(1)（最重要）：Adam 常能识别大盘趋势反转（顶/底） ⇒ 服务波段交易与正股仓位管理。
  • 用途(2)：部分帖文给出日内 0DTE 明确信号 ⇒ 服务短期做单。
  • 用户两个额外要求：① 判定要区分这两类用途；② 分析要引入当日 ES 价格走势；③ 暂不接入自动下单。

实现链路

层文件职责
① 即时分类（taxonomy）PyTools/jobs/x_posts_adam_signal_v2.py对称 taxonomy：方向/类别(reversal_top·bottom, trend_continuation, intraday_0dte, level_map, position_mgmt, commentary)/周期/确信度/条件性/价位/证据/用途；每批 commit + 死锁重试 + 单实例锁
② 当日叙事链PyTools/jobs/x_posts_thread_v3.py按交易日升序串联：thread_role(thesis_open/confirmation/update/level_ref/exit/invalidation/standalone) + day_bias + day_status(intact/weakening/invalidated) + day_key_levels + day_thesis；日状态快照表 x_day_threads
③ 当日价格语境PyTools/py_lib/day_price_context.py用帖文自带 es_spot 采样构建首末价/当日高低/15 分钟压缩路径；支持 cutoff（无前视）与可选 OHLC 升级
④ 通知PyTools/py_lib/adam_post_notify.py固定主题 BBT Adam信号（同线程 ✓）美观 HTML 邮件 + 桌面横幅（仅信号帖）；当日事件（翻转/失效）高优先级提醒
⑤ 事件提醒/回填PyTools/jobs/adam_day_events.py / adam_realtime_classify.py / backfill_comprehensive_slots.py事件幂等提醒；实时链 v2→v3→事件；5m 槽位回填
⑥ 事件研究PyTools/jobs/adam_reversal_event_study.py以 invalidated / bias 翻转 为事件：d5/d10/d20 方向调整收益 + fav20 最大有利位移 + 20 日新高/低 + day_type 分层 + 基准 Welch 检验
