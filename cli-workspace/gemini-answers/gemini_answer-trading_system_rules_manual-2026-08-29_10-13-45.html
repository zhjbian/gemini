本手册系统性整合了量化交易分析平台（包括 ai_tape_analyst.py、order_flow_sentinel.py、bbt_signals 网页端及衍生量化计算模块）中定义的所有核心规则。内容涵盖底层数据清洗、微观盘口定性、量化指标评分、大模型研判约束、SPX 0DTE Gamma 做市商对冲模型以及跨资产流动性验证标准。

第一部分：Order Flow 订单流分析规则 (Order Flow Analysis Rules)

日内定性 (Day Type) 判定规则

系统依据盘前 (PM) 及常规交易时段 (RTH) 的累计 Delta、价格变动效率、关键价位吸收特征，将盘面划分为五种核心定性基调（Day Type），默认为 Balanced（均衡震荡）。

1. Passive Buying (被动买方吸收)

判定满足以下任意一条即可定性为 Passive Buying：

  • 全天逆势吸收:
    • 条件: total_delta < -15000 且 rth_price_change >= -5.0
    • 机制: 全天出现超万手大额主动净卖出，但 RTH 价格极为抗跌，甚至收盘跌幅不足 5 点，表明主动砸盘筹码被大额被动限价买单全部吸收。
  • 盘前极端抛压吸收:
    • 条件: pm_delta < -500000 且 pac >= 0.9 且 pm_price_change > 10.0 且 rth_price_change >= -10.0
    • 机制: 盘前极端抛压被完全消化并逆势大涨，RTH 开盘后未出现破坏性回调。
  • 量价大级别逆势反转:
    • 条件: total_delta < 0 且 rth_price_change >= 20.0 且 bull_absorb_count > bear_absorb_count
    • 机制: 全天净 Delta 为负，但价格逆势暴涨超过 20 点，且看多吸收信号数量显著多于看空吸收。
  • 底部极值区域被动托盘:
    • 条件: bottom_zone_delta < -10000 且 bottom_zone_dper > -1.5
    • 机制: 在全天价格振幅最低的 25% 极值区域（Bottom 25% Zone）内，承受超过 1 万手主动抛盘，但该区域的 DPER (价格推进效率) 大于 -1.5（即每 1000 手净卖单打压价格不足 1.5 点），确认为主力被动筑底。

2. Passive Selling (被动卖方拦截)

判定满足以下任意一条即可定性为 Passive Selling（为防止将单边暴跌趋势误判为高位拦截，硬性限制 rth_price_change > -20.0）：

  • 全天逆势滞涨:
    • 条件: total_delta > 15000 且 rth_price_change <= 5.0
    • 机制: 全天出现超万手大额主动净买入，但 RTH 价格严重受阻无法上涨，表明主动买盘撞上冰山卖单墙。
  • 盘前极端买盘拦截:
    • 条件: pm_delta > 500000 且 pac >= 0.9 且 pm_price_change < -10.0 且 rth_price_change <= 10.0
  • 量价大级别冲高回落:
    • 条件: total_delta > 0 且 rth_price_change <= -25.0 且 bear_absorb_count > bull_absorb_count
  • 顶部极值区域被动拦截:
    • 条件: top_zone_delta > 10000 且 top_zone_dper < 1.5
    • 机制: 在全天价格振幅最高的 25% 极值区域（Top 25% Zone）内，消耗超过 1 万手买盘，但每 1000 手买盘推升价格不足 1.5 点，确认为主力高位派发。

3. Active Buying (主动多头推进)

满足以下条件定性为 Active Buying：

  • 触发条件: total_delta > 15000 且 rth_price_change >= 20.0 且 dper >= 1.5
  • 机制说明: 主动买盘大额放量，价格单边大幅拉升，且全天价格推进效率 DPER 达到至少 1.5 点 / 1000手 Delta。

4. Active Selling (主动空头推进)

满足以下条件定性为 Active Selling：

  • 触发条件: total_delta < -15000 且 rth_price_change <= -20.0 且 dper >= 1.5
  • 机制说明: 主动卖盘大额放量砸盘，价格单边大幅下挫，且打压效率绝对值达到至少 1.5 点 / 1000手 Delta。

5. Balanced (多空均衡震荡)

  • 判定基准: 未满足上述四类极端特征时，归类为 Balanced 状态。

日内强度定量评分计算规则 (Scoring Breakdown, 100分制)

系统通过 5 个微观与宏观维度对当前订单流定性的确定性进行量化打分（满分 100 分）： 总分 = Zone DPER Score + Delta Score + Volume Score + 30-Min Score + 5-Min Score

(1) Zone DPER Score (关键区域价格推进效率, 40% 权重, 满分 40 分)

  • Passive Buying:
    • 公式: min(max(-bottom_zone_dper, 0.0) / 2.0, 1.0) * 40.0
    • 说明: 底部区域 DPER 越偏负，说明打压每 1000 手的价格下挫越小，吸收越强；当负值达到 -2.0 时即获满分 40 分。
  • Passive Selling:
    • 公式: min(max(-top_zone_dper, 0.0) / 2.0, 1.0) * 40.0
  • Active Buying / Active Selling:
    • 公式: min(abs(dper) / 2.0, 1.0) * 40.0

(2) Delta Score (全天累积 Delta 绝对强度, 10% 权重, 满分 10 分)

  • 计算公式: min(abs(total_delta) / 30000.0, 1.0) * 10.0
  • 说明: 当全天累计 Delta 绝对值达到 30,000 手时获得满分 10 分。

(3) Volume Score (总成交量基础, 10% 权重, 满分 10 分)

  • 计算公式: min(total_volume / 2000000.0, 1.0) * 10.0
  • 说明: 全天总成交量达到 2,000,000 手（200万手）基准时获得满分 10 分。

(4) 30-Min Divergence / Push Score (30分钟背离与推进, 20% 权重, 满分 20 分)

  • Passive Buying (30分钟背离):
    • 触发: tb30d < -5000 且 tb30p >= -10.0
    • 公式: 10.0 + min((abs(tb30d) - 5000.0) / 10000.0, 1.0) * 10.0
    • 说明: 基础分 10 分，根据超出 5000 手的抛压程度线性递增至最高 20 分。
  • Passive Selling (30分钟背离):
    • 触发: tu30d > 5000 且 tu30p <= 10.0
    • 公式: 10.0 + min((abs(tu30d) - 5000.0) / 10000.0, 1.0) * 10.0
  • Active Buying / Selling (30分钟顺势推进):
    • 公式: min(abs(rth_price_change) / 40.0, 1.0) * 20.0

(5) 5-Min Squeeze / Acceleration Score (5分钟微观极值与挤压, 20% 权重, 满分 20 分)

  • Passive Buying (5分钟微观挤压):
    • 触发: tb5d < -4000 且 tb5p >= -10.0
    • 公式: 10.0 + min((abs(tb5d) - 4000.0) / 11000.0, 1.0) * 10.0
  • Passive Selling (5分钟微观挤压):
    • 触发: tu5d > 4000 且 tu5p <= 10.0
    • 公式: 10.0 + min((abs(tu5d) - 4000.0) / 11000.0, 1.0) * 10.0
  • Active Buying / Selling:
    • 触发: 5 分钟放量推进 tu5d > 4000 且 tu5p >= 10.0，赋分最高 20 分。

(6) 等级划分区间 (Grade Boundaries)

  • High (高确定性): 总分 >= 75 分
  • Medium (中度可靠): 45 分 <= 总分 < 75 分
  • Low (弱信号/噪音): 总分 < 45 分

订单流实时信号哨兵规则引擎 (Order Flow Sentinel Rule Engine: 5-Min Ticks & DOM)

本模块对应量化系统核心常驻哨兵进程 order_flow_sentinel.py，在常规交易时段（RTH 06:30 - 13:00 西雅图时间）每 5 分钟快速轮询一次。系统采用双引擎并行毫秒级定量扫描架构，分别对“已成交成交流 (Ticks Flow)”与“未成交挂单深度微观势能 (DOM Flow)”进行实时特征提炼与联合裁决；当且仅当命中极端异动条件时，事件驱动唤醒大模型 AI 进行全盘深度研判。

1. 5分钟 Tick 成交流规则引擎 (Ticks Flow Engine)

(1) 基础微观评估与全局预设 (Base Pre-conditions)
  • 多头预设 (pre_bullish):
    • 规则: RTH 累计 Delta 占总成交量比例 Delta%Vol <= 1.5%
    • 逻辑: 确认空头已释放充分，处于低位筑底反转区。
  • 空头预设 (pre_bearish):
    • 规则: RTH 累计 Delta 占总成交量比例 Delta%Vol >= 1.5%
    • 逻辑: 确认多头已推高至高位，处于顶部翻转区。
(2) 微观触发因子 (Conditions A / B / C / D)
  • 条件 A (15分钟放量动能):
    • 多头: 最近 15 分钟 Delta >= 8000 手，或单根 5 分钟 Delta >= 6000 手。
    • 空头: 最近 15 分钟 Delta <= -8000 手，或单根 5 分钟 Delta <= -6000 手。
  • 条件 B (高效推进与单根极端吞没):
    • 多头: 单根 5 分钟价格上涨 >= 10.0 点伴随正 Delta。
    • 空头: 单根 5 分钟价格下跌 <= -10.0 点伴随负 Delta。
  • 条件 C (CVD 累计背离回撤/回升):
    • 多头: 累计 Delta 从日内低谷回升 >= 10000 手，或 30 分钟净 Delta > 5000 手。
    • 空头: 累计 Delta 从日内高峰回撤 >= 10000 手，或 30 分钟净 Delta < -5000 手。
  • 条件 D (持续价量共振):
    • 多头: 最近 30 分钟价格上涨 >= 15 点且净 Delta > 0。
    • 空头: 最近 30 分钟价格下跌 <= -15 点且净 Delta < 0。
(3) 三大 Tick 优化规则引擎 (Optimized Rules)
  • 方案一：2 小时大单净量安全网 (Big Trade Net Filter):
    • 统计过去 2 小时机构大单（>= 100 手）累计净量：
    • 若 2 小时大单净买量 >= 3000 手：硬性屏蔽所有看空信号 (blocked_bear_by_block_buy)。
    • 若 2 小时大单净卖量 <= -3000 手：硬性屏蔽所有看多信号 (blocked_bull_by_block_sell)。

  • 方案二：被动吸筹/分发背离强制激活 (Passive Absorption / Distribution):

    • 被动多头吸筹 (passive_bull_absorption):
      • 条件: 过去 30 分钟 net_delta_30m < -4000，但价格跌幅收窄 price_change_30m >= -5.0，且处于低位 price_position_pct <= 30.0%。
      • 裁决: 强制激活看多判定。
    • 被动空头分发 (passive_bear_distribution):
      • 条件: 过去 30 分钟 net_delta_30m > 4000，但价格涨幅受阻 price_change_30m <= 5.0，且处于高位 price_position_pct >= 70.0%。
      • 裁决: 强制激活看空判定。

  • 方案三：时间衰减加权大单评分与相对位置覆写:

    • 低位机构吸筹强行触发 (inst_bull_accumulation):
      • 条件: 近 2 小时大单净量 >= 3000 手或得分 >= 1500，且处于低位 price_position_pct <= 45.0%。
      • 裁决: 强制触发看多 HIGH 信号。
    • 高位机构出货强行触发 (inst_bear_distribution):
      • 条件: 近 2 小时大单净量 <= -3000 手或得分 <= -1500，且处于高位 price_position_pct >= 55.0%。
      • 裁决: 强制触发看空 HIGH 信号。

2. 5分钟 DOM 盘口深度规则引擎 (DOM 500ms Time-Series Engine)

(1) 500ms 离散网格与微观动量建模
  • 600 步长离散网格: 在 5 分钟（300 秒）窗口内，划分 600 个 500ms 均匀时间戳，采用前向填充（Forward-Fill）追踪全景 0-199 档挂单深度。
  • 5 分钟微观动量 (imb_momentum):
    • 公式: imb_momentum = late_w_imb (后半段 2.5m 均值) - early_w_imb (前半段 2.5m 均值)
    • 判定: 若动量显著偏正（> +0.04），表明买单防线持续增厚抢筹；若动量显著偏负（< -0.04），表明买盘撤单溃退，卖压加速堆积。
  • 500ms 阶跃差分 (Spoofing / Stacking):
    • 相邻 500ms 步长之间近端挂单净减 < -50 计为撤单；净增 > 50 计为堆单。
  • 持续真空秒数统计 (vacuum_sec):
    • 累计单档挂单不足 10 手的步长总数并转换为秒数，要求实质断层持续 >= 1.5 秒以规避瞬态扰动。
(2) 核心微观结构规则判定

  • 流动性真空逼空与破位规则 (Vacuum Squeeze & Breakdown):

    • 多头逼空触发 (dom_bull_vacuum_squeeze):
      • 条件: 最近 5 分钟检测到卖方真空持续 vacuum_ask_sec >= 1.5s 且近端失衡或动量看多（imb_near > 0.05 或 imb_momentum > 0.04）且买方堆单加固 stack_bid >= stack_ask。
      • 裁决: 判定卖方防线出现实质性断层，强制激活 Bullish HIGH 信号。
    • 空头雪崩触发 (dom_bear_vacuum_breakdown):
      • 条件: 最近 5 分钟检测到买方真空持续 vacuum_bid_sec >= 1.5s 且近端失衡或动量看空（imb_near < -0.05 或 imb_momentum < -0.04）且卖方堆单压制 stack_ask >= stack_bid。
      • 裁决: 判定买方托单断层溃败，强制激活 Bearish HIGH 信号。

  • 微观冰山密集吸收与最高覆写规则 (Micro Iceberg Burst):

    • 底部强冰山吸筹 (dom_bull_iceberg_burst):
      • 条件: 最近 5 分钟多头冰山单 iceberg_bull >= 2 次（大额市价卖单砸盘但价格不跌），且处于相对中低位 price_position_pct <= 45.0%。
      • 裁决: DOM 被动吸收享有最高覆写权 (Override)，强制激活 Bullish HIGH 信号。
    • 高位强冰山派发 (dom_bear_iceberg_burst):
      • 条件: 最近 5 分钟空头冰山单 iceberg_bear >= 2 次（大额市价买单推升但价格不涨），且处于相对中高位 price_position_pct >= 55.0%。
      • 裁决: 判定为主力高位冰山挂单拦截，强制激活 Bearish HIGH 信号。

  • 虚假撤单诱多/诱空陷阱过滤规则 (Spoofing Trap Filter):

    • 诱多假托单陷阱 (spoof_bull_trap):
      • 条件: 买方撤单占比 >= 70% 且 spoof_bid > 2 * spoof_ask（总撤单 >= 10 次）。
      • 裁决: 硬性封杀一切看多信号 (block_bull_by_spoof = True)。
    • 诱空假压单陷阱 (spoof_bear_trap):
      • 条件: 卖方撤单占比 >= 70% 且 spoof_ask > 2 * spoof_bid（总撤单 >= 10 次）。
      • 裁决: 硬性封杀一切看空信号 (block_bear_by_spoof = True)。

3. 双引擎联合裁决与 AI 协同触发时序 (Dual-Engine Execution Flow)

  1. 毫秒级本地评估: 常规 5 分钟轮询由本地 Python 纯规则在 2-3 秒内完成 56,000+ Ticks 与 600 个 500ms DOM 网格步长的提取与规则评估，零网络阻塞；

  2. 信号汇总与陷阱安全防护:

    • 若 Tick 引擎触发 HIGH 信号，或 DOM 引擎触发 HIGH 信号，汇总激活对应多空方向；
    • 若命中 DOM 诱多/诱空撤单陷阱，执行最高级别安全拦截，强制覆写取消触发；

  3. 冷却校验 (Cooldown): 同一方向在 30 分钟内仅允许触发一次，防止短线连续脉冲引发重复报警；

  4. 事件驱动唤醒 AI 深度研判: 通过校验后，后台异步唤醒 run_ai_tape_analyst(date_str, target_time, --sentinel)，由 Gemini 大模型对 5 分钟全景深度与明细展开宏微观综合语义研判，并在 Web 仪表盘和邮件中发布最新结论。

实时信号置信度等级判定规则 (Signal Strength: High vs Normal)

1. Bearish (看空) 判定为 High 强度的完整规则

必须满足：

  1. 全局预筛选: Delta%Vol >= 1.5%

  2. 且满足以下微观条件之一:

    • 放量主动砸盘 (条件 A): 最近 15 分钟 Delta <= -8000 手，或任意单根 5 分钟 Delta <= -6000 手。
    • 高效下挫与被动吸收 (条件 B): 单根 5 分钟价格下跌 <= -10.0 点且伴随负 Delta，或分析结论中检出“买盘被吸收”、“Supply Trap”或“买盘竭尽”。
    • 累积背离回撤 (条件 C): RTH 累计 Delta 从当日最高点回撤 >= 10000 手，或最近 30 分钟累计 Delta <= -5000 手。
    • 持续下行斜率 (条件 D): 最近 30 分钟价格下跌 <= -15.0 点且最近 30 分钟 Delta 为负值。

2. Bullish (看多) 判定为 High 强度的完整规则

必须满足：

  1. 全局预筛选: Delta%Vol <= 1.5%

  2. 且满足以下微观条件之一:

    • 放量主动拉升 (条件 A): 最近 15 分钟 Delta >= 8000 手，或任意单根 5 分钟 Delta >= 6000 手。

3. 动态生命周期三重退出风控铁律 (Triple Exit Rules)

  • 主动提早止盈 (Take Profit)：当净权利金衰减达到开仓价值的 65%（即以原权利金的 35% 价格买回）时，无论到期时间如何，系统立即市价平仓锁定利润。
  • 硬性止损保护 (Stop Loss)：当价差买回成本攀升至初始开仓权利金的 2.20 倍 时，无条件触发市价止损买回，果断切断黑天鹅极端单边行情损失。
  • 强制时间全清 (Time Stop - 12:30 PST)：美西时间 12:30（美东 15:30，距美股收盘 30 分钟）前，系统执行强制平仓，清空所有活跃的 0DTE 垂直价差持仓，绝对禁止持仓过夜，彻底消除美式期权被行权分派及盘后跳空风险。

4. 双批次阶梯开仓与分级止盈机制 (Dual-Tranche Tiered Take-Profit)

  • 开仓仓位规则 (2 Spreads Scale-Out)：每次空仓状态触发开仓时，系统一次性卖出 2 个 Spread（总计 2 手，每手宽度 1.0 点），拆分为两个独立批次（Tranche 1 与 Tranche 2）。
  • 第一次止盈 (Tranche 1 - 初级快速减仓)：
    • 止盈比例：权利金衰减达到 40%（即盘口买回价跌至原权利金的 60%）时触发市价平仓；
    • 设计意图：以较低获利门槛迅速锁定第一手收益，释放心理压力并迅速回本，消除单次交易的下行风险敞口。
  • 第二次止盈 (Tranche 2 - 深度奔跑收割)：
    • 止盈比例：权利金衰减达到 75%（即盘口买回价跌至原权利金的 25%）时触发市价平仓；
    • 设计意图：留存 1 手让利润充分奔跑，深度榨取 0DTE 日内 Theta 时间价值加速归零的红利。
  • 止损与时间平仓一致性：两手价差严格执行相同的 2.20 倍权利金硬止损 与 12:30 PST 强制全清 铁律。

9. QuantPivot 统计学动态波动率耗竭与反转边界开仓决策规范 (QuantPivot Statistical Volatility Reversion Bands Entry Rules)

为进一步增强期权卖方在日内关键极值位置开仓的统计学确定性，系统将基于 30 日真实日线波动范围（True Daily Range）的 QuantPivots (Open, H1, H2, L1, L2) 正式纳入开仓决策与行权价锚定架构：

1. 数学模型与统计学理论 (Mathematical Principles)
  • 样本数据口径：严格基于标的过去 30 个交易日交易所标准交易时段（RTH 09:30 - 16:00 EST / 06:30 - 13:00 PST）的纯日线 OHLC 历史数据。
  • 日内多空扩张百分比定义：
    • 上涨扩张百分比: up = 100 * (High - Open) / Close
    • 下跌扩张百分比: down = 100 * abs(Open - Low) / Close
  • 30 日样本均值与标准差：
    • aveUp = avg(up)，upSD = stdev(up, ddof=1)
    • aveDown = avg(down)，downSD = stdev(down, ddof=1)
  • 当日动态波动率边界计算公式（基准 pO 为美东 09:30 / 美西 06:30 官方 RTH 开盘价）：
    • H2 (极端上行耗竭位 / 阻力 2): H2 = pO + ((aveUp + upSD) / 100) * pO
    • H1 (平均期望上行耗竭位 / 阻力 1): H1 = pO + (aveUp / 100) * pO
    • pO (RTH 开盘锚点): pO = RTH Open
    • L1 (平均期望下行耗竭位 / 支撑 1): L1 = pO - (aveDown / 100) * pO
    • L2 (极端下行耗竭位 / 支撑 2): L2 = pO - ((aveDown + downSD) / 100) * pO
  • 统计学概率分布意义：H1 与 L1 代表单日日内多空波动的期望均值边界；H2 与 L2 代表均值 + 1 倍标准差，历史经验表明约 84% 以上交易日的 RTH 极值均被有效约束在 H2 之下与 L2 之上，构筑了高确定性的期权卖方防御防线。
2. 双向开仓决策与微观共振仲裁规范 (Bidirectional Entry Rules)
