报告范围与结论

执行原则（沿用既有文档纪律，未做任何偏离）：

  • 文档是规则权威 ⇒ 代码向文档对齐（凡文档明确定为决策规则者，代码必须实现）；
  • 凡既未实现、也不打算实现的规则，从代码删除并在文档如实标注（如 EMA 乖离率判定、EMA 缠结否决）；
  • 单一权威：同一规则不得在两处重复实现（如第 0 层门槛只在 auto_mechanisms，引擎委托）；

  • 最小行为面：能不改行为就不改（如删除从未生效的死分支属零行为变更）。

代码修复：触发 / 布防跨进程链路

根因（审计 #8 / #9 / #10 的共同上游）

自动布防发生在 5 分钟哨兵子进程 PyTools/order_flow_analysis/order_flow_sentinel.py，而条件单触发发生在常驻进程 bbt_data_web（OptionSellerManager._monitor_loop，周期 MONITOR_INTERVAL_SEC = 8.0）。条件单表 order_flow_option_seller_conditional_orders 没有 level 列，因此：

  • quant_pivot_level / quant_pivot 无法跨进程携带；
  • 触发侧读到的 qp_level 恒为 None，导致「三维准入」被 if sub_scen in [...] and qp_level: 整段跳过；
  • 退出即 quant_pivot=None，使锚位与 Gamma 墙双双失效。

修复策略：把级别 / L1H1 / 锚位编码进布防条件单的 notes 机器标记（不改表结构、不动 schema），触发侧兜底解析还原。

解析增强：四级兜底 + 抽成纯函数

原先内联实现有两处缺陷：① 只认旧字面量 QuantPivot X，ARMED 单（只含 (H1=…)）恒解析为 None；② 逻辑写死在巨型方法里，无法被单测覆盖（这正是后文「未绑定先使用」漏检的原因之一）。

现抽为两个 @staticmethod（option_seller_manager.py:2579 / :2609）：

@staticmethod
def parse_qp_meta(order: Dict[str, Any], notes_str: str):
    """解析 QP 级别与 L1/H1 标记。

    级别兜底顺序：① 记录字段 quant_pivot_level → ② 旧字面量 `QuantPivot X`
    → ③ 新机器标记 `[QPLevel: X]` → ④ 布防 notes 内的 `(H1=…)` 形式。
    """
    import re as _re
    qp_level = (order or {}).get('quant_pivot_level')
    if not qp_level:
        for _lv in ('L1', 'L2', 'H1', 'H2'):
            if ('QuantPivot %s' % _lv) in notes_str or ('QPLevel: %s' % _lv) in notes_str:
                qp_level = _lv
                break
    if not qp_level:
        _m = _re.search(r'\(([LH][12])=', notes_str)
        if _m:
            qp_level = _m.group(1)
    is_l1_h1 = (order or {}).get('is_l1_h1_pivot_trade')
    if is_l1_h1 is None:
        if 'L1H1:' in notes_str:
            # ★ 2026-09-13 修正：比较串同样要小写 —— 原写法 (note.lower()) 去匹配大写
            #   'L1H1: true' 恒为 False，导致自动布防的 L1/H1 单丢失 pivot 交易标记
            is_l1_h1 = ('l1h1: true' in notes_str.lower())
        else:
            is_l1_h1 = bool(qp_level in ('L1', 'H1'))
    return qp_level, is_l1_h1

@staticmethod
def derive_target_short_anchor(notes_str: str, direction: str, qp_level, qp_order):
    """锚位（短腿硬约束，单一权威）。

    优先 notes 机器标记 `[Anchor: n]`（布防时计算，跨进程不丢失）；
    否则退化为按 level + QuantPivot 重算（H2/L2 → 二级位，H1/L1 → 一级位）。
    重算结果与 level 全无着落时返回 None ⇒ 引擎侧退回旧「硬锚 = 墙/边界」行为。
    """
    import re as _re
    anchor = None
    try:
        _ma = _re.search(r'\[Anchor: ([0-9.]+)\]', notes_str)
        if _ma:
            anchor = float(_ma.group(1))
    except Exception:
        anchor = None
    if not anchor and qp_order:
        try:
            _h1 = float(qp_order.get('h1') or 0.0); _h2 = float(qp_order.get('h2') or 0.0)
            _l1 = float(qp_order.get('l1') or 0.0); _l2 = float(qp_order.get('l2') or 0.0)
            if direction == 'BEARISH':
                anchor = _h2 if qp_level == 'H2' else _h1
            elif direction == 'BULLISH':
                anchor = _l2 if qp_level == 'L2' else _l1
        except Exception:
            anchor = None
    try:
        anchor = float(anchor) if anchor else None
    except Exception:
        anchor = None
    return anchor
