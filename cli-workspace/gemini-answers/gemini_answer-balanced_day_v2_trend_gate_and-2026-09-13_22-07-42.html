元数据小节的字段口径（据代码实测）

§1.2.1 TICK 元数据

  • 原始逐笔（MW 导出 CSV）：Timestamp（毫秒）/ Price / Size（手）/ Side；Side = ASK = 主动买（消耗卖盘），Side = BID = 主动卖（消耗买盘）
  • 时间轴统一毫秒；秒/毫秒/微秒混用会导致窗口判定恒 False，曾被误判为「成交流缺失 NO_TICK_FLOW」
  • 落格：bin_idx = (t_ts − start_ts) // 500（sample_interval_ms = 500）；逐格产出 had_buy[] / had_sell[]（布尔成交标记）、buy_vol_bins[] / sell_vol_bins[]
  • 价格路径：price_change、rth_high / rth_low、ATR
  • 大单：单笔 ≥ 500 手，2 小时窗口 + 半衰期指数衰减
  • 价格轴索引：traded_by_price（5 分钟）/ traded_by_price_lb（30 分钟回看）
  • 代码位置：PyTools/order_flow_analysis/order_flow_feature_generator.py、dom_sentinel_evaluator.py

§1.2.2 DOM 元数据

  • 原始逐档行：Timestamp / Side(BID·ASK) / Level(0..199) / Price(绝对价) / Size(手)
  • 快照结构：ts -> {bids:{level:size}, asks:{level:size}, bid_px:{level:px}, ask_px:{level:px}}
  • 网格重采样：sample_interval_ms = 500、600 点 = 5 分钟；覆盖率 = 实际读到快照数 ÷ 理论应有快照数；记录快照数、最大间断、来源回退
  • 档位梯队列（全章权重与阈值的公共口径）：近端 0-5 / 中端 5-20 / 深层 20-120 / 远端 >= 120
  • 逐格中间量：near_bids_500ms[] / near_asks_500ms[]、diff_bids[] / diff_asks[]（±50 手为撤单/加单判别阈值）
  • 价格轴索引：按绝对价格分桶（bid_px / ask_px）；Level 是相对盘口偏移、会随盘口移动，跨时对齐必须用绝对价
  • 远端墙：Level >= 120 且 Size >= 800 手
  • 代码位置：PyTools/option_seller/balanced_day_data.py（原 move_end_data.py）、PyTools/order_flow_analysis/dom_sentinel_evaluator.py

§1.2.4 合成与判定层（非指标）：13 项方向加权聚合（§1.3.1/§1.3.2）、DOM 微观综合研判投票 DOM 综合多 N/4 空 M/4、spoof_* 一票否决、方向裁决与中性细分（§1.6/§1.6.5/§1.7）、DOM 侧速查表。

配置迁移实现（零中断）

def load_balanced_day_config() -> dict:
    """平衡日边界通道配置：新文件优先 → 旧名文件回退（并自动迁移）→ 缺省值 ✓"""
    cfg = dict(BALANCED_DAY_DEFAULTS)
    d = _read_json_config(BALANCED_DAY_CFG)
    migrate = False
    if d is None:
        d = _read_json_config(BALANCED_DAY_CFG_LEGACY)
        migrate = d is not None
    for k in BALANCED_DAY_DEFAULTS:
        if d and k in d and d[k] is not None:
            cfg[k] = d[k]
    if migrate:
        try:
            _write_json_config(BALANCED_DAY_CFG, cfg)
            BBLog.logger_os().warning(f"OptionSeller 平衡日边界: 配置已由旧名迁移 → {BALANCED_DAY_CFG}")
        except Exception:
            pass
    return cfg

def _proximity(px, day_high, day_low, lv, tol):
    """现价到「上侧边界族 / 下侧边界族」的最近距离（点）"""
    ups = ([day_high] if day_high is not None else []) + [L for L in lv if L >= px]
    dns = ([day_low] if day_low is not None else []) + [L for L in lv if L <= px]
    du = min((abs(px - b) for b in ups), default=None)
    dd = min((abs(px - b) for b in dns), default=None)
    return du, dd
  • 方向准入：bull ≥ bear 且 bull ≥ 45 ⇒ BULLISH；bear > bull 且 bear ≥ 45 ⇒ BEARISH（P 到位即可达 45）

  • 组数：groups = 0 if final < threshold else max(1, min(int(groups_cap or 1), 1)) ⇒ 一律 1 组
  • 一票否决：is_spoof_trap（dom_metrics.is_spoof_trap 或行级）⇒ 直接出局
  • v1 影子对照：通道每次判定仍调用一次 v1，结果写入 evidence.v1_shadow（score / groups / direction / veto），不影响行为
